# Tic Tac Toe
A Simple 2-player Tic-Tac-Toe game written in c.

## How to play
- player 1 chooses any number between 1 to 9
- player who has typed the number displays X or O
- second turn goes to second player when the first symbol is displayed for first player
- get three symbols in a row horizontally,vertically or diagonally.
